# 日报/周报模板

只有用户明确要求“日报”“今日汇报”“周报”“本周汇报”等内容时，才使用这个模板。

## 日报

日报追加到：

`{NOTES_DIR}/{DATE}.md`

结构：

```markdown
# {DATE} 日报

1. 修改 `<任务>`：整体思路是先……再……，主要解决了……，现在……
2. 梳理 `<模块>`：我重点确认了……，这块对后续……有影响。
3. 排查 `<问题>`：目前定位到……，下一步准备……
```

规则：

- 每一条都用编号。
- 语气要自然，像能直接开口汇报的话。
- 修改类内容必须写清为什么改、整体思路和当前结果。
- 不要把每个小动作都写成流水账。
- 如果对话里没有明确进展，不要硬编。

## 周报

周报写入：

`{NOTES_DIR}/{DATE}-周报.md`

结构：

```markdown
# {DATE} 周报

1. 修改 `<任务>`：整体思路是……，这周主要把……处理到了……。
2. 梳理 `<模块>`：把……这条流程理清楚了，重点确认了……，后面写类似功能时可以直接参考。
3. 排查 `<问题>`：主要问题在……，目前结果是……，下周准备……
```

规则：

- 多篇笔记可用时，优先按项目或模块归纳。
- 合并同类内容，不要逐天照抄日报。
- 语气比日报稍微整体一点，但仍然自然。
- 只有来源材料支持时，才写结果、影响和下一步。
